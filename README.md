# Толмач

Перевод англоязычных веб-новелл на русский. Дизайн — в `design/`, решения по
правам на чужой текст — в `docs/rights-policy.md`.

Сейчас в коде один кусок: ссылка или файл → текст главы → перевод с
глоссарием → сколько это стоило. Ни сайта, ни входа, ни оплаты пока нет.

## Зачем начали с этого

Все цены в макетах — 490 ₽ за сто глав, 1 190 ₽ за триста, квота вместо
безлимита — стоят на оценке «около 3 ₽ за главу на быстрой модели». Оценка
взята из расчёта, а не из замера. Пока настоящего числа нет, экран оплаты
рисовать можно, а включать нельзя.

Второе, что этот кусок показывает: правда ли глоссарий даёт тот перевод,
ради которого всё затевается. Прогоните одну главу с глоссарием и без — и
станет видно, есть продукт или нет.

## Запуск

```bash
npm install
cp .env.example .env   # и вписать ключ
```

Пробная глава лежит в `samples/` — она придумана для примеров, настоящий
замер нужно делать на настоящих главах.

```bash
# быстрой моделью, с глоссарием
npm run tolmach -- перевести samples/chapter-en.txt \
    --глоссарий samples/glossary.json --регистр возвышенный --модель fast

# то же сильной моделью — сравнить качество и цену
npm run tolmach -- перевести samples/chapter-en.txt \
    --глоссарий samples/glossary.json --регистр возвышенный --модель strong

# прямо со страницы
npm run tolmach -- перевести https://example.com/chapter-147 --в out/147.txt
```

После перевода печатается расход: токены на входе и выходе, сколько ушло
в кэш и из кэша, цена в долларах и рублях, и пересчёт на сотню глав.

## Замер себестоимости

Для этого есть стенд. Список глав — по одной ссылке или пути в строке,
образец в `samples/sources.example.txt`.

```bash
# пилот из трёх глав: покажет цену и остановится
npm run замер -- мой-список.txt --глоссарий настоящий-глоссарий.json

# полный прогон, со страховкой
npm run замер -- мой-список.txt --глоссарий настоящий-глоссарий.json \
    --все --предел 300
```

Без ключа `--все` стенд прогоняет три главы, печатает, во что обойдётся
остальное, и останавливается. Так вы видите счёт до того, как он выставлен.
`--предел` обрывает прогон по достижении суммы в рублях.

Что печатает: медиану и среднее за главу, разброс, цену на тысячу слов,
сколько глав попало в кэш, сколько было отказов и ошибок. И главное —
что из этих чисел следует для тарифов: маржа при полной выборке квоты,
маржа при типичных 60% и на скольких главах в месяц тариф выходит в ноль.

Медиана здесь честнее среднего: длина главы у разных авторов отличается
вдвое, и одна очень длинная перекашивает среднее.

Отчёт ложится в `out/` (он в `.gitignore`) и содержит только цифры —
ни оригиналов, ни переводов.

### Как собрать список

Полусотни глав хватит, чтобы число перестало прыгать. Берите из тех новелл,
на которые целитесь: разброс длины у разных авторов — главный источник
разброса цены.

Свой список не коммитьте и скачанные главы в репозиторий не кладите. Это
чужой текст, и стенду он нужен только на время прогона.

### Что делать с результатом

Сравните медиану с ценой тарифа, поделённой на квоту. Для «Читателя» это
4,90 ₽ на главу, для «Запойного» — 3,97 ₽. Если медиана выше — тариф убыточен
на том, кто выбирает квоту целиком, и надо двигать либо цену, либо квоту.
Стенд считает это сам и печатает прямо в отчёте.

Заодно посмотрите на строку про кэш. Со второй главы одной книги попадания
должны появиться. Если их нет — что-то в начале промпта меняется от запроса
к запросу и обнуляет кэш; это лишние деньги на каждой главе.

Глоссарий и правила уходят в промпт отдельными блоками с пометкой на
кэширование. Со второй главы одной книги строка «из кэша» должна перестать
быть нулевой; если она нулевой осталась — что-то в начале промпта меняется
от запроса к запросу, и кэш обнуляется.

## Что внутри

| Файл | Что делает |
| --- | --- |
| `src/extract.ts` | Достаёт текст главы из файла или со страницы |
| `src/glossary.ts` | Термины и таблица «кто кому ты», сборка блока для промпта |
| `src/translate.ts` | Перевод через Claude, разбор отказов и ошибок |
| `src/cost.ts` | Токены в деньги |
| `src/cli.ts` | Консоль: перевести одну главу |
| `src/measure.ts` | Стенд замера себестоимости на списке глав |
| `src/config.ts` | Модели, цены, регистры, курс |

Цены моделей в `src/config.ts` — прайс на 2026-06-24. Они меняются: перед
серьёзным подсчётом сверьтесь с актуальным.
